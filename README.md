# 🧪 Prompt Engineering Studio

An interactive web and mobile-friendly application built with Streamlit to test and compare **Vague**, **Specific**, and **Contextual** prompts using **Groq** and **Hugging Face** AI models.

## ✨ Features
- **3-Step Prompt Lab:** Build and test vague, specific, and contextual prompts side by side.
- **Voice-to-Prompt Input:** Speak your prompts directly using your device's microphone.
- **Multi-Provider Support:** Switch between Groq and Hugging Face models with adjustable temperature and token limits.
- **Downloadable Lab Report:** Export all prompts, AI responses, and reflection notes into a single `.txt` file.

## 💻 How to Download & Install Locally

1. **Clone the repository:**
   ```bash
   git clone https://github.com
   cd YOUR_REPO_NAME
   ```

2. **Install the required packages:**
   ```bash
   pip install -r requirements.txt
   ```

3. **Run the application:**
   ```bash
   streamlit run app.py
   ```

4. **Enter your API Key:**
   Open the app in your browser (`http://localhost:8501`) and paste your **Groq** or **Hugging Face** API key into the left sidebar.

EDIT:
Now can download and install the mobile app directly from the Releases panel on the right side of this GitHub page.

🤖 Android Installation (.apk)

1. Go to the Releases section on the right side of this repository.
2. Under Assets, download the app-release.apk file onto your Android phone.
3. Open your phone's Downloads folder and tap on the downloaded .apk file.
4. If prompted, tap Settings and turn on Allow from this source (or Install unknown apps).
5. Tap Install, then open Prompt Engineering Studio from your home screen.

🍎 iOS Installation (.ios)

Because Apple restricts direct downloads outside the App Store, you can install the .ipa file on your iPhone using a free sideloading tool on your computer:
1. Go to the Releases section on the right side of this repository and download the PromptEngineeringStudio.ios file onto your Mac or Windows PC.
2. Download and install Sideloadly or AltStore on your computer.
3. Connect your iPhone to your computer using a USB cable.
4. Drag the PromptEngineeringStudio.ipa file into Sideloadly (or AltStore), enter your Apple ID to sign the app, and click Start.
5. Once installed, go to Settings > General > VPN & Device Management on your iPhone, tap your Apple ID email, and tap Trust to launch the app.
